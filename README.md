# 🧪 SIFIT — Qualidade de Software

Este repositório contém o trabalho individual desenvolvido para a disciplina de **Extensão em Qualidade de Software**, tendo como foco o sistema **SIFIT** e a aplicação de práticas relacionadas à análise de requisitos, planejamento e execução de testes manuais.

O projeto reúne documentos e registros produzidos durante as atividades da disciplina, buscando organizar de forma clara todo o processo de avaliação da qualidade do sistema.

---

## 🎯 Objetivos do Projeto

O trabalho tem como principais objetivos:

* Analisar e documentar os requisitos e funcionalidades do sistema SIFIT;
* Elaborar cenários e casos de teste;
* Realizar testes manuais nas funcionalidades selecionadas;
* Identificar, registrar e acompanhar possíveis falhas encontradas;
* Organizar evidências e resultados obtidos durante os testes;
* Aplicar conceitos e boas práticas de qualidade de software.

---

## 📂 Organização do Repositório

Os arquivos do projeto estão separados em diretórios de acordo com cada etapa da documentação:

* 📁 **Requisitos** — Documentação e análise dos requisitos selecionados do sistema.
* 📁 **Plano de Testes** — Informações relacionadas ao planejamento, escopo, estratégia e critérios utilizados nos testes.
* 📁 **Cenarios de Testes** — Descrição dos cenários e casos de teste elaborados para as funcionalidades analisadas.
* 📁 **Bugs** — Registro das inconsistências e problemas identificados durante a execução dos testes.
* 📁 **Relatórios** — Documentos contendo os resultados e considerações finais das atividades realizadas.
* 📁 **Evidências** — Imagens, capturas de tela e outros registros utilizados para comprovar a execução dos testes.

---

## 🧪 Abordagem de Testes

Durante o desenvolvimento do trabalho, foram utilizadas diferentes abordagens para avaliar o comportamento das funcionalidades do sistema, incluindo:

* **Testes funcionais**
* **Testes positivos**
* **Testes negativos**
* **Testes exploratórios**
* **Análise de cenários de uso**

Para a documentação e organização das atividades, foram utilizados recursos como **Markdown, GitHub, tabelas, checklists e BDD (Gherkin)**.

O processo foi dividido principalmente nas etapas de **planejamento, preparação dos cenários, execução dos testes, registro das evidências e elaboração dos resultados**.
